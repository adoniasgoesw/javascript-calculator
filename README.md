# JavaScript Calculator

A basic calculator project built with HTML, CSS, and vanilla JavaScript to practice functions and programming logic.

## Preview

![Calculator with an iPhone-inspired design](./assets/calculator-preview.png)

## Project Goal

Build a calculator step by step, understanding how to organize functions, handle user input, and connect JavaScript logic to a web interface.

## Learning Objectives

- Create and call functions.
- Work with variables, operators, and conditional statements.
- Handle click events.
- Read and update elements using the DOM.
- Convert user input into numbers.
- Validate input and handle invalid operations.

## Planned Features

- Addition, subtraction, multiplication, and division.
- Support for decimal numbers.
- Clear the display.
- Delete the last entered character.
- Handle division by zero.
- Responsive layout.

These features describe the planned scope and are not yet confirmed as implemented.

## Technologies

- HTML
- CSS
- JavaScript — no frameworks.

## Project Status

🚧 In development.

This README will be updated as features are implemented.

## Running Locally

Once the initial project files are available:

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Development Approach

Implement arithmetic operations with JavaScript functions rather than `eval()`, keeping the calculation logic explicit and easier to understand.
